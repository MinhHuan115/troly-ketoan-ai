🛡️ Về cảnh báo bảo mật của Windows

Đừng lo — đây là chuyện bình thường với mọi app mới từ developer độc lập. Để Windows hết cảnh báo, app phải mua chứng chỉ ký số EV (~$300–700/năm) mà Microsoft bán cho các công ty lớn. Đây chỉ là một tool học tập bình thường. Bạn chỉ thấy cảnh báo này 1 lần duy nhất khi cài lần đầu.

1

Lúc tải về (trình duyệt)

Trình duyệt có thể báo "...isn't commonly downloaded". Di chuột vào file đang tải → bấm ••• hoặc mũi tên ↑ → chọn Keep (Chrome) / Keep anyway (Edge).

2

Lần đầu chạy app (Windows)

Giải nén file ZIP → mở thư mục → double-click TroLyKeToan.exe. Nếu hiện bảng xanh "Windows protected your PC" → bấm More info → Run anyway.
